
# Contributing

Thank you for your interest in contributing!

## How to contribute
1. Fork the repo and create a feature branch.
2. Run tests: `npm test`.
3. Submit a PR with a clear description and links to specs.

## Design notes
- Encodings and schemas are **reference‑only** and may change.
- Discuss major changes via GitHub Issues before submitting a PR.

## DCO
By contributing, you agree your contribution is under Apache‑2.0.
